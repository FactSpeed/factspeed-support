## 📌 Règles simples

1. **Une seule question par issue** — plus clair pour tout le monde.
2. Indiquez votre **version** (visible en haut à droite du logiciel) et votre
   **module** concerné.
3. ⚠️ **Ne collez JAMAIS de données clients réelles** (noms, montants, NIF…)
   dans une issue publique — anonymisez vos captures et exemples.
4. Les issues ne sont **pas** un canal de facturation/licence : pour toute
   question d'achat ou d'activation, contactez le support WhatsApp.

## 🔒 Confidentialité

FactSpeed fonctionne **100 % en local** : nous n'avons accès à aucune de vos
données. Un diagnostic peut vous être demandé sur WhatsApp — il contient des
informations techniques (version, journal d'erreurs), jamais vos documents.
